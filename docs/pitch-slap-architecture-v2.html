Weekly Constraint System
7 Acquisitions / Week
  • Pulled from ESPN transaction history daily
  • Resets each Monday with new matchup
  • Move to last priority after any claim
  • At 5+ used: high-need adds only
  • At 6 used: "last move — confirm before acting"
  • Surfaced on Home + Waivers pages
15 IP Minimum / Week
  • Tracked daily from ESPN/MLB IP totals
  • Resets each Monday — no carryover
  • If trending below 15 by Thursday: alert
  • If safely above by Wednesday: can sit risky starters
  • Blocks punt recommendations if below 15
  • Interacts with 2-start streaming logic
Waiver Priority (1–8)
  • Pulled from ESPN each morning
  • 1-day processing period
  • Top 3: confident recommendations
  • Bottom 3: surface "safe" targets + AT RISK flag
  • Ownership velocity + priority = urgency flag
  • "Claim tonight or lose the window"
Roster Slot Awareness
  • C x2, 1B, 2B, 3B, SS, MI, CI, OF x5
  • UTIL x2, P x10, BN x5, IL x3
  • MI = 2B or SS · CI = 1B or 3B
  • Every add recommendation includes a drop suggestion
  • Drop cost shown: net cat impact
  • Never recommend add without roster impact
Category State Model
WIN
Leading comfortably. Gap exceeds cat-specific threshold. Do not sacrifice this cat to help another.
FLOPPABLE
Leading but opponent within striking range. Defensive mode — monitor, do not bench key contributors.
FLIPPABLE
Losing but closeable. Active target — stream, add, or prioritize starters contributing here.
LOSS
Losing, gap too large. Accept loss — if gap > 2× threshold, recommend punt. Redirect effort.
Validation Framework — validate.py (Step 5, Blocking)
Schema Checks
  • Expected columns in all fact tables
  • Correct data types enforced
  • No nulls in required fields for active players
Range Checks
  • ERA: 0.00–15.00
  • WHIP: 0.00–4.00
  • OBP: .100–.600
  • xFIP/SIERA: 1.00–8.00
  • Barrel%: 0%–35%
  • Ownership: 0%–100%
Completeness
  • 8 rosters returned (0 = auth fail)
  • Your roster ≥ 20 active players
  • FA pool > 200 players
  • Statcast > 700 players when fresh
Crosswalk Integrity
  • All rostered players have MLB ID
  • WARN if any unmatched
  • FAIL if > 3 unmatched
  • Unmatched → data gap section only
Ground Truth Checks
  • Roster ERA vs ESPN ±0.10
  • SvHd total vs ESPN displayed
  • OBP definition match confirmed
  • Acquisition count vs ESPN
  • IP total vs ESPN weekly
Staleness + Auth
  • Source > 25h old → WARN
  • ESPN 0 rosters → AUTH_FAILURE
  • All failures logged to validation_log
  • Dashboard banner on WARN or FAIL
